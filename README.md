# Ларьок одкровень

Браузерна гра-ларьок: персонаж у віконці, щоденні монети й пророцтва за різними мантичними системами.

## Запуск

```bash
npm install
npm run dev      # локальний сайт на http://localhost:5173
npm run build    # збірка в dist/ (саме це публікує Vercel)
```

## Арти й шрифти

Оригінали лежать у папках `Arts/` і `Fonts/` (у git вони не потрапляють). Після зміни арту:

```bash
node scripts/optimize-art.mjs
```

Скрипт обрізає шари по контуру, робить webp у `public/art/`, записує позиції в `src/art/manifest.json` і стискає шрифти.

## Для перевірки

Додай до адреси: `?reset` — почати з нуля (знову отримати 5 монет), `?coins=N` — виставити баланс.
